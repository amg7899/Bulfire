# BULFIRE website

Static website (HTML + CSS + a little JS, no build step) for BULFIRE Ltd., published with GitHub Pages; it replaces the WordPress site at bulfire.ecoes.eu.

- `index.html` – Home page (English); every section gets its own folder (`about-us/`, …)
- `bg/` – the same pages in Bulgarian
- `assets/` – styles, scripts, logos and images
- `tools/` – `forest.py`, which draws the transparent forest landscape in `assets/img/deco/`
